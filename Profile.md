¿QUE ES GIT?
Git es un sistema de control de versiones que permite guardar y controlar pues varios cambios de un proyecto 


¿QUE ES GITHUB?
Pues aqui es una plataforma que nos deja almacenar repositorios justo de git el control de versiones y se puede trabajar de manera grupal o colavorativa 

DIFERENCIAS 
Git es la herrramientaque controla versiones de un proyecto y pues GitHub es la plataforma donde lo almacenamos 

¿QUE ES UN COMMIT?
El commit podria ser justo el registro de los cambios que realizas en un proyecto y sirve para guardar las versiones de cada archivo 

¿QUE ES UN BRANCH?
Un branch pues seria un rama de trabajo independiente que nos deja realizar cambios sin modificar la rama principal 

¿QUE ES UN PULL REQUEST?
Podria ser una solicitud para meter cambios que se han realizado en un rama con otra y pues la que es normalmente la principal y luego ver los cambios antes de cambiar o hacer el merge
